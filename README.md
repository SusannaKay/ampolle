# 🧪 Ampolle!

A potion-sorting puzzle game for mobile browsers. No ads, just *play & chill*.

**Play:** https://ampolle.vercel.app

## How to play
Tap a flask, then tap another to pour the top color into it. You can only pour onto the same color or into an empty flask. You win when every flask holds a single color.

## Features
- Endless procedurally generated levels with rising difficulty (from 3 to 12 colors)
- A DFS solver checks that every level can be solved before you get it
- Mystery potions ❓ from level 6
- Undo, hint (the solver suggests the next move) and one extra flask per level
- Progress saved locally; sound effects synthesized with the Web Audio API
- A single HTML file with zero dependencies

## Stack
Vanilla HTML, CSS and JavaScript · deployed on Vercel · Vercel Web Analytics
